万一真要恢复，怎么操作（点开看步骤）
  1. 在飞牛上解开备份包：tar xzf contract-app_xxx.tgz -C /tmp/restore （里面是 app.db、manifest.txt、uploads.tgz）
  2. 停掉系统：docker compose stop
  3. 把现有的 data 目录改名留底：mv data data.broken.日期
  4. 建回 data 并把备份放进去：库放 data/app.db， 解开 uploads.tgz 得到 data/uploads/
  5. 起系统：docker compose up -d
  6. 对一下 manifest.txt 里的行数与系统里的数量是否一致

提醒：备份跟数据库在同一块盘（都在存储空间1）上，盘坏了会一起没。 建议定期点一次【下载到本机】，或者把备份目录改到别的存储空间，才算真正的保险。
